# Defning the amount of permutations I will be doing and giving them an empty vector to go into. 
nperm = 1000
perm_coefs <- vector(length = nperm)

# Loop for permutations. Breaking up the association between group size and ECV by using sample function. Then doing a linear model test for each permutation and defining those results at perm_coefs. These coefficients are then piped into tidy function with is then piped to filter to look at only the slops for Group size and pulling out those slope estimates. Note there is no replacement of values in this loop.
for (i in 1:nperm){
  d_perm <- d
  d_perm$Group_size <- sample(d$Group_size)
  
  perm_coefs[[i]] <- lm( ECV ~ Group_size, data = d_perm) |>
    tidy() |>
    filter(term == "Group_size") |>
    pull(estimate)
}

For this step I needed to permeate the linear model test of ECV as a function of Group size. The permeation repeats 1000 times and randomizes the order of group size values to achieve this. The p value associated with my original slope coefficient is: 7.26e-11 which indicates that Group size does have an effect on ECV.

# Step 8

# Defining about many bootstraps I am doing and setting up an empty vector for the values to go in. 
nboot <- 1000
boot_coefs <- vector(length = nboot)

# Bootstrapping loop with replacement. I randomize the group size values using sample and doing a linear model test for each bootstrap. Then piping all those values into the tidy function and piping them into filter to only look at the group size coefficients. The loop then pulls the estimates for each coefficient.
for (i in 1:nboot) {
  d_boot <- d[sample(nrow(d), replace = TRUE), ]
  boot_coefs[[i]] <- lm(ECV ~ Group_size, data = d_boot) |>
    tidy() |>
    filter(term == "Group_size") |>
    pull(estimate)
}

# Visualizing the coefficients which appear to be normal.
hist(boot_coefs)
# Quantile method for determining the the 95% confidence interval and writing out what that interval is. 
ci <- quantile(boot_coefs, c (0.025, 0.975))
cat("Bootstrap 95% CI:", ci[[1]], "to", ci[[2]], "\n")
Bootstrap 95% CI: 1.499596 to 3.263426 
# Defining the beat1, the standard error of my bootstrapping and determining the t-crit value for my bootstrapping to determine the 95% confidence interval manually.
beta_1 = mean(boot_coefs)
boot_se <- sd(boot_coefs)
boot_t_crit <- qt(0.975, df = nrow(d)-2)

# Using theory-based method of determining the 95% confidence itnerval. 
boot_ci_lower <- beta_1 - boot_t_crit*boot_se
boot_ci_upper <- beta_1 + boot_t_crit*boot_se

# Writing out the values of the theory-based 95% confidence interval.
cat("Manual Bootstrap 95% CI:", boot_ci_lower, "to", boot_ci_upper, "\n")
Manual Bootstrap 95% CI: 1.503353 to 3.336166
